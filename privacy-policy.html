atoyomi - プライバシーポリシー

最終更新日: 2024年7月14日

1. はじめに

atoyomi（以下「本拡張機能」）は、ユーザーのプライバシーを尊重し、個人情報の保護に努めています。本プライバシーポリシーは、本拡張機能がどのような情報を収集し、どのように使用するかを説明します。

2. 収集する情報

2.1 ウェブサイトのコンテンツ

本拡張機能は、ユーザーが「あとで読む」として保存したウェブページの以下の情報を収集します：

  • ページのタイトル
  • ページのURL
  • 保存日時

2.2 収集しない情報

本拡張機能は以下の情報を収集しません：

  • 個人を特定できる情報（名前、メールアドレス等）
  • ページの内容やテキスト
  • ブラウジング履歴（保存したページ以外）
  • その他の個人情報

3. 情報の使用目的

収集した情報は以下の目的でのみ使用されます：

  • 保存したページの一覧表示
  • 保存したページへの再アクセス機能
  • Xプラットフォーム（旧Twitter）での共有機能

4. 情報の保存場所

すべての情報はユーザーのブラウザのローカルストレージにのみ保存されます。外部サーバーやクラウドサービスに情報が送信されることはありません。

5. 第三者への情報提供

本拡張機能は、ユーザーの情報を第三者に販売、転送、共有することはありません。ただし、ユーザーが明示的にXプラットフォームでの共有機能を使用した場合を除きます。

6. データの削除

ユーザーは拡張機能をアンインストールすることで、すべての保存データを削除できます。また、保存したページにアクセスすると自動的にリストから削除されます。

7. セキュリティ

本拡張機能は、Chrome Extension Manifest V3の最新のセキュリティ基準に準拠しています。

8. お問い合わせ

本プライバシーポリシーに関するご質問は、GitHub Issuesまでお寄せください。

atoyomi - Privacy Policy

Last updated: July 14, 2024

1. Introduction

atoyomi (the "Extension") respects user privacy and is committed to protecting personal information. This Privacy Policy explains what information the Extension collects and how it is used.

2. Information We Collect

2.1 Website Content

The Extension collects the following information from web pages that users save for "read later":

  • Page title
  • Page URL
  • Save date and time

2.2 Information We Do Not Collect

The Extension does not collect:

  • Personally identifiable information (name, email address, etc.)
  • Page content or text
  • Browsing history (other than saved pages)
  • Any other personal information

3. How We Use Information

Collected information is used solely for:

  • Displaying the list of saved pages
  • Providing re-access functionality to saved pages
  • Sharing functionality on X platform (formerly Twitter)

4. Information Storage

All information is stored only in the user's browser local storage. No information is transmitted to external servers or cloud services.

5. Third-Party Information Sharing

The Extension does not sell, transfer, or share user information with third parties, except when users explicitly use the X platform sharing feature.

6. Data Deletion

Users can delete all saved data by uninstalling the extension. Additionally, saved pages are automatically removed from the list when accessed.

7. Security

The Extension complies with the latest security standards of Chrome Extension Manifest V3.

8. Contact

For questions about this Privacy Policy, please contact us through GitHub Issues.
